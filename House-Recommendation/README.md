# House Recommendation Analysis

This project was completed as part of the Fall 2024 Data Dive program with the Illinois Data Science Club at the University of Illinois Urbana-Champaign.

Our team analyzed a housing dataset containing more than 200,000 observations to explore factors related to housing value and identify potential property opportunities. We cleaned and analyzed the dataset, explored relationships among housing characteristics, and applied predictive modeling techniques including Linear Regression and Random Forest.

The project combined data analysis and machine learning to develop a housing recommendation approach based on property characteristics and model results. Our team presented the analysis and findings at the conclusion of the Data Dive program.
